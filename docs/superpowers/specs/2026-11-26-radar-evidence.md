# Source evidence and project discovery

A submitted Instagram post should preserve the order and identity of source media. A requested slide index is a navigation hint. A preview image, including one returned for multiple indices, establishes no slide count. For enumerated children record an outcome for each child, including skipped media and unreadable images, and keep the per-image OCR separate. Render this evidence from saved Markdown on both sites. Historical records with no measurement have unknown coverage.

Evaluate existing-project fit and an independently brainstormed build idea for each finding. The latter describes a user, problem, smallest build and measurable experiment. Its basis may include a retrieved online source; distinguish the proposed application from observations. Keep private context and draft ideas in the owner view. The existing Community Lab publication path controls public experiments.

Acceptance examples include Quentin's metadata-only capture, a carousel with duplicate preview thumbnails, a failed middle slide, and existing records without new fields. Verify public Markdown excludes private proposals. Do not promote a metadata-only capture into a source-supported recommendation.
